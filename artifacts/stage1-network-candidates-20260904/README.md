## 共同编辑提示

创建 `16:9` macOS 桌面概念；无边框提醒只占屏幕上方约 `25–28%`，下方工作界面继续可见；固定两行文案为“给下一段留一点余白。\n让目光去远处停一会儿。”；保持低细节、稳定亮度、低打扰，不出现水印、Logo、人物、按钮、计时、进度、医疗符号、圆角通知卡片或游戏界面。

各稿只改变来源主题：抽象光影、半透明材质、单一水纹、安静钟表、缓慢流水、单片落叶或柔和日出。钟表不得表现成倒计时；流水不得出现飞溅；落叶避免悲伤或冥想 App 套路；日出避免高光与励志海报感。

## 当前观察

- 钟表的时间哲学最直接，但也最容易被理解成工作时限；
- 流水比单一涟漪更自然，但纹理运动必须足够慢；
- 落叶的“放下”语义明确，但视觉中心略强；
- 日出温和易懂，但最容易退化成普通壁纸；
- 半透明材质目前最不依赖具体叙事，适合作为低打扰基准。

所有结论都只是内部初筛，尚未替代真实用户反馈。
