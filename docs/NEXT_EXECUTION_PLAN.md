> 生效日期：2026-09-06

## 推进原则

1. 一次任务只处理一个明确交付物，不在同一轮中扫描全部图片、实现功能并做最终验收。
2. 候选比较一次最多加载 `3` 张图片；先用已有记录筛选，再按需查看原图。
3. 当前不实现完整计时器、行为引擎、设置页或数据报表，避免把视觉问题与提醒时机问题混在一起。
4. 自动化和无需打断用户的验证由 Codex 完成；真实硬件、真实通知和试用者反馈明确列为外部验证。
