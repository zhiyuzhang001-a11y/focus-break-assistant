# 每日分类图库

> 最新在线规则已改为六类各 10 张、无需密钥、整批替换，见 [ONLINE_RESERVOIR.md](ONLINE_RESERVOIR.md)。下面旧在线额度与来源限制仅记录历史版本。

菜单栏「今天想看什么？ / 分类图库…」打开选择页。六类为自然风景、宇宙星空、动物、城市、人物、卡通插画。支持多选、沿用上次、今天随机及关闭每日询问。人物在线偏好可选生活纪实、运动、时尚。

应用运行时，每天首次可用且不在全屏状态时显示一次；全屏、睡眠、会话不可用、图库选择或提醒正在显示时延后，每分钟检查。展示当天即记录，关掉窗口不会重复弹出，跨重启保留记录。关闭窗口沿用原有来源；点击应用或沿用上次会切换至分类图库。取消每日询问不影响从菜单手动打开。需要应用启动（或用户自行启用登录时启动），不会替用户打开登录启动开关。

每类显示真实图库首张缩略图；空分类使用系统分类图标并标明数量和来源能力，不伪造图库内容。自然风景已有六张内置实拍照片。其他分类初始可为空，用户可从各卡片导入 JPG、PNG、HEIC。每个分类单独保存，原图不被修改，重复导入同分类按内容去重。保存位置为 `~/Library/Application Support/FocusBreakAssistant/CategoryImages/<分类>`。主动导入是长期保存，不受在线缓存自动删除影响。导入记录注明用户来源及许可未独立核实。

今日图库从所选分类的内置图、导入图、匹配分类的在线缓存中轮换；记住轮换次序，完整一轮后重排且避免交界重复。未选中的分类不加入轮换，全部为空或损坏才临时回退内置风景，并在菜单状态明确提示。今天随机从有图片的分类选择一种。分类内目前没有收藏或“不再显示”功能。

在线来源仍为 Pexels，需用户在应用中配置密钥。开放风景、动物、城市、人物，按所选类型轮流安排请求；分类来源记录于缓存清单。旧版无分类缓存按风景兼容处理。宇宙和卡通仅本地导入，尚未接入可自动更新的专门来源。人物细分只影响以后发起的在线搜索，不会自动给本地图片识别分类。

全分类共用每天最多成功 3 张、最多 10 张 / 30 MiB 的缓存额度。当天额度已用完后换分类不会再额外下载，可使用本地图库并等待次日。配置页和菜单中的在线来源入口仍可访问 Pexels 原页。选回原有文件夹或内置照片会退出分类轮换，保留分类偏好。

验证：分类偏好/去重/空选择、日界和重启、关闭询问、本地导入隔离和原图保护、随机轮换重启边界、空/缺失分类、卡通和宇宙不发起照片 API 请求；原有屏幕适配、提醒、缓存测试继续运行。真实在线下载仍待密钥配置后验收。

2026-09-07 显示适配调整：真实提醒窗口改为跟随图片原比例，最大宽为所在屏幕可用宽度的 90%、最大高为可用高度的 85%，顶部居中并以约 2.8 秒展开。常见横图、竖图、方图无需固定横框留白或裁掉主体；竖图和全景不强求占据屏幕面积一半。旧视觉矩阵仍用于固定区域兼容检查，新几何测试验证实际自适应窗口的比例和完整显示。
