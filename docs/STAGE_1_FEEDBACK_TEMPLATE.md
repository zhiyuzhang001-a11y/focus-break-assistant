# Horizon Gap 试用反馈

请先正常使用电脑，再从菜单栏选择“预览一次提醒”。提醒会自动消失，不需要点击或确认。体验后只回答以下三题。

## 固定问题

1. 提醒出现时，你是否感到突然被打断？  
   `没有 / 有一点 / 明显`

2. 你是否能轻松看清两行文字？  
   `能 / 需要费力 / 没看清`

3. 你把它理解成什么？  
   `短暂看向远处的建议 / macOS 系统通知 / 任务完成或保存提示 / 其他：____`

## 可选备注

- 使用环境：`浅色 / 深色 / 复杂壁纸 / 代码或文字工作 / 其他`
- 屏幕：`内置屏幕尺寸或外接显示器型号`
- 缩放：`默认 / 更多空间 / 更大文字 / 不清楚`
- 一句话备注：`____`
