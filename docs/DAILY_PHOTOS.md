# 每日照片与缓存

> 最新在线规则已改为六类各 10 张、无需密钥、整批替换，见 [ONLINE_RESERVOIR.md](ONLINE_RESERVOIR.md)。下面旧在线额度与来源限制仅记录历史版本。

已实现 Pexels API 接入。菜单栏 →「每日照片 · Pexels」→「配置每日照片…」，点击「获取 API 密钥」前往 https://www.pexels.com/api/ 申请，再在应用的密码框中保存。无需把密钥发给聊天助手。密钥保存在 macOS 钥匙串，不写入项目、日志或普通设置。

配置成功会启用每日更新并切换到每日照片。当前尚未提供真实密钥，因此真实在线下载尚未验收，不能视为已经每天获取新照片。

- 每个本地自然日最多成功下载 3 张，按日期切换风景主题和搜索页；跳过当前缓存中的重复照片。来源不足、损坏或网络失败时可以少于 3 张。
- 应用运行时启动检查，之后每 15 分钟检查；成功当天不再请求，失败自动重试间隔至少 1 小时。睡眠/关机期间不下载，恢复运行后检查；不补下载错过的多天。
- 每次最多尝试 6 个候选文件。照片按原始比例缩放至宽 2560，单张下载上限 6 MB，下载过程在内存中限量读取，使用无磁盘 URLCache 的临时网络会话。
- 专用目录：`~/Library/Caches/FocusBreakAssistant/DailyPhotos`。最多 10 张且不超过 30 MiB（含来源清单的空间预留），先清旧文件再写新文件。容量优先，所以大图可能导致保留少于 10 张。系统也可能主动清除此目录。
- 缓存中的 `sources.json` 保存作者、Pexels 原页、下载时间；适用 Pexels License：https://www.pexels.com/license/ 。菜单中的照片来源项可以打开当前照片原页。
- 每日照片随机轮换，轮换记录跨重启保留。断网使用已有缓存；缓存空或损坏时退回内置照片。切换到本地文件夹或内置照片不会删除缓存；后台更新可单独关闭。
-「关闭每日更新」保留已有缓存和钥匙串密钥。「清空下载缓存」同时关闭更新，防止刚清空又被自动下载填满；重新启用通过配置入口。清空不重置当日下载额度。
- 用户选择的原图、系统照片图库和 `ImportedPhotos` 导入目录均不参与缓存清理。当前尚未实现缓存照片的收藏/永久保存按钮。

验证覆盖：每日额度与重复刷新、HTTP 401、损坏照片、缓存满时淘汰、启动时孤立文件修复、清空后旧任务不能写回、原图不受清理影响。网络测试通过隔离 URLProtocol 响应运行，不消耗真实 API 配额，也不冒充真实在线验收。

2026-09-06 分类升级：在线搜索已按当天所选的风景、动物、城市、人物分配，每日 3 张和缓存上限仍为全库总量。宇宙和卡通不使用 Pexels 自动抓取。详见 [分类图库说明](CATEGORY_LIBRARY.md)。
