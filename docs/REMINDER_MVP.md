# 自动提醒第一版

2026-09-06，已从手动预览原型接入自动提醒。属于可自用的开发版本，尚未完成发布签名、公证和长期实机验收。

## 使用

双击 `.build/FocusBreakProbe.app` 即可启动菜单栏应用；不再需要命令行参数。重复启动由本机进程锁阻止，退出或崩溃后锁自动释放。

菜单只保留：距下次提醒的估计时间/延后原因、暂停/恢复、预览下一张、设置和退出。设置分为“提醒、图片库、通用”三页，间隔、停留时间、图库与登录启动移入对应页面。默认间隔 45 分钟；间隔和暂停选择保存在本机。更改间隔开始新周期。手动预览不计入自动提醒次数。

## 确定性规则

- 使用单调时钟，每约 5 秒检查一次轻量活动信号；时间阈值会有约一个采样周期的误差。
- 无输入达到 3 分钟后暂停累计；满 5 分钟视为自然休息，取消待显示提醒并开始新周期。
- 达到阈值后显示提醒。“稍后 5 分钟”安排继续使用 5 分钟后重试；“跳过本次”、Esc 或默认超时开始完整间隔的新周期。可选未处理时追加一次 5 分钟提醒，默认关闭；追加提醒再次超时后恢复完整间隔。自然休息取消待提醒和追加提醒。
- 全屏或全屏状态未知时延后，退出全屏后仍需满足活动条件；自然休息会取消待显示提醒。
- 系统睡眠、显示器睡眠/唤醒、会话切换事件重置周期；超过 30 秒的回调空档也重置，不补计睡眠或挂起时间。
- 应用重启不恢复旧累计时间；手动暂停保留当轮累计，暂停期间不计时，恢复后继续，期间自然休息则会重置。
- 图库选择、文件夹选择或已有浮层显示期间不再自动弹出；真正成功创建浮层后才标记本轮已提醒。
- 点击“开始休息”进入 5 分钟休息倒计时，结束后开始完整提醒周期；屏幕睡眠/会话变化会取消旧周期。
- 交互提醒支持点击按钮和 Esc 收起，默认停留 30 秒，可设为 15/30/60/120 秒（不含展开和收起动画）。预览提供收起、收藏与屏蔽，不改变自动提醒周期。Esc 不触发重试；超时仅在开启追加提醒时重试一次。
- 交互浮层允许接收鼠标和键盘焦点，使用非激活面板，不切换前台应用；仅在本应用事件中匹配 Esc，不记录键盘内容。全屏识别沿用已有窗口边界/可选辅助功能信号；普通锁屏的精确识别仍受已有信号限制，采用保守处理。

## 登录时启动

使用 macOS `SMAppService.mainApp`，首次运行不注册、不默认启用。仅用户点击开关时注册或注销；需要批准时打开系统“登录项”设置。开发版本建议固定在“应用程序”目录后再启用，移动或重建签名后可能需要重新设置。此次未开启用户的登录启动，未进行真实注销/登录验证。

## 验证

- `swift test`：45 分钟阈值、同周期一次、3/5 分钟 idle、全屏/未知上下文延后、暂停恢复、睡眠/回调空档、间隔更改和非法时钟输入。
- `--verify-automatic-reminder`：独立临时设置，2 秒测试阈值，真实系统信号和真实定时回调；要求当前非全屏且处于使用中，12 秒内检查自动浮层恰好一次、周期确认及前台焦点未变化。此命令不修改正式提醒间隔。
- 非交互浮层仍验证点击穿透；菜单预览改为验证可交互、前台应用不变。AppKit 测试覆盖三页设置布局、按钮回调、Esc 响应和幂等关闭。
