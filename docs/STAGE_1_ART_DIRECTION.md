# Stage 1 视觉原则与素材筛选

> 初次记录：2026-09-04  
> 当前状态：已从“画风优先”纠正为“体验目标优先”。三张既有方向稿只保留为探索记录，不构成山水、水墨或远景约束。

## 目标

提醒本身只是让用户意识到“该把目光从近处屏幕移开”的短暂触发器，不应成为需要继续盯着欣赏的内容。

视觉需要同时做到：

- 看得见，但不刺眼、不闪烁、不迫使响应；
- 安静、克制，有余白和停顿感；
- 不抢焦点、点击穿透、自动消失；
- 不像系统通知、任务完成、广告或健康警告；
- 哲学感来自空间、节奏、光线和留白，不依赖山水、禅意符号或说教文案；
- 不暗示预防或治疗眼部疾病，只帮助形成短暂离屏节律。

“让目光去远处停一会儿”描述的是用户接下来的行为，不要求画面必须出现远山、湖泊或风景。

## 视觉边界

优先选择低细节密度、缓和明暗关系、稳定亮度和大面积留白的画面。提醒在一两秒内应能被理解，之后把注意力送回现实空间，而不是吸引用户研究画面。

直接排除：

- 水印、来源不明、授权页缺失或只找到二次搬运版本的素材；
- 高亮闪白、霓虹、高饱和撞色、快速运动或密集纹理；
- 人脸、人物主体、Logo、品牌、按钮、图标、倒计时和进度条；
- 明显像通知卡片、游戏过场、冥想广告或任务完成界面的构图；
- 需要长时间观看才能理解，或漂亮到让人继续盯着屏幕的画面。

## 开放的候选方向

以下是用于扩大搜索面的类别，不是必须各选一个，也不限定具体画风：

1. **抽象光与空间**：柔和光带、模糊边界、微弱水平结构、暗部中的呼吸感。
2. **材质与留白**：半透明纸张、玻璃、织物、雾化表面、低对比度颗粒和缓慢展开的层次。
3. **时间与停顿**：窗影、光线移动、水面微纹、空旷色域或其他能表达“暂停一下”的非叙事画面。
4. **时间器物**：钟表、沙漏、日晷等可以表达有限时间与阶段转换，但不能出现倒计时、截止或催促感。
5. **自然与宇宙循环**：流水、日出、地球自转/公转、季节变化、落花和落叶。运动必须足够慢，并在静态画面中也成立。
6. **生命过程**：萌芽、孵化和出生可以表达开始，但情绪与叙事吸引力很强，只作为后备探索，不在首轮使用动物生产或幼崽特写。

具象风景仍可进入候选池，但必须和其他类型接受同一套体验筛选，不能因为“看向远方”就自动获得优先级。

用户提出的钟表、沙漏、流水、地球运动、落花、落叶、日出和动物出生均进入概念池。首轮优先验证流水、单叶、柔和日出和克制的时间器物；地球运动需要单独核对素材授权、能耗和是否过度吸引视线；动物出生暂缓，因为它很容易成为需要观看的故事，而不是促使离屏的提示。

## 素材来源策略

1. 优先从官方原始页面寻找无水印、可追溯授权且允许修改和用于 App 的高分辨率素材。
2. 保存素材原始链接、作者、下载日期、许可证名称和许可证页面快照或文字记录。
3. 不从 Pinterest、图片聚合站、搜索缩略图或来源不明的转载页取图，也不做去水印处理。
4. 网络素材只作为基础层，允许为产品进行裁切、调色、降低细节、制作深浅版本和边缘透明过渡。
5. 只有网络素材无法满足关键体验时，才补充自行生成或程序绘制的部分；不预设必须使用生成图。
6. 中文文案始终由原生 Swift 绘制，不烘焙进图片。

## 筛选流程

1. 从上述三个开放类别收集 `6–9` 个候选，每个候选先通过水印与授权硬检查。
2. 把候选统一放进真实桌面、代码界面和深浅背景，不先评价“美不美”。
3. 首轮只检查四件事：是否刺眼、是否看清意图、是否误认通知、是否让人继续盯屏。
4. 保留最多 `3` 个明显不同的候选给用户比较，不要求在既有三张方向稿中选择。
5. 用户确认体验方向后，再制作正式深浅资产和原生动画，并重跑焦点、输入、全屏、通知共存和辅助显示验证。

## 动画约束

- 动画只用于让提醒自然出现和离开，不制造戏剧性；
- 默认节奏仍以约 `6–7 sec` 的完整可见周期为基线，具体位移和透明度在实机中调整；
- 开启“减少动态效果”时缩短或取消位移，只保留温和显隐；
- 避免大幅视差、缩放、闪烁和需要眼睛追踪的运动。
