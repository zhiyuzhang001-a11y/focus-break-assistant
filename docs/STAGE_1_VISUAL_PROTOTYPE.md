# 阶段 1：Horizon Gap 视觉提醒原型

> 启动日期：2026-09-04  
> 状态：Stage 1 收尾中；首版工程基线保留用于行为验证，但视觉方案已被否决。阶段 0 已关闭，当前下一任务是把现有概念收敛为最多三个体验候选。

## 已实现

- 保留 `252 × 76 pt`、右侧 `26 pt` 安全边距和可见区域顶部约 `20%` 的固定布局；
- 固定使用“给下一段留一点余白。让目光去远处停一会儿。”，不加入标题、按钮、倒计时或成功反馈；
- `--preview-reminder [13|14]` 可直接预览一次提醒，默认采用更易读的 `14 pt`；
- `--render-visual-matrix DIR` 自动生成浅色桌面、深色桌面、复杂壁纸、代码编辑器和通知共存五种环境下的 `13/14 pt` 对照，共 10 张 PNG；
- 两种字号均完成不抢焦点、不可成为 key/main window 和点击穿透的运行时验证；
- 深浅模式、减少动态效果、增强对比度和减少透明度继续沿用阶段 0 已验证策略。
- 预览专用菜单栏入口已实现，包含“预览一次提醒”和“退出预览”，可通过 `scripts/run-preview-menu.sh` 启动；
- 菜单栏自动验收曾发现 `.accessory` 策略会让应用短暂成为前台，现已改为 `.prohibited` 并验证前台应用保持不变；
- 固定三问反馈模板已建立于 [`STAGE_1_FEEDBACK_TEMPLATE.md`](STAGE_1_FEEDBACK_TEMPLATE.md)。

## 当前判断

首轮矩阵证明了工程行为，但 `252 × 76 pt` 圆角底面过于接近系统通知，缺少画面、艺术性和哲学感，不再作为产品视觉方向。远山雾幕、抽象光隙和水墨天幕三张后续方向稿也只作为探索记录，不要求最终素材采用山水、水墨或远景。当前改为以眼睛友好、低打扰、余白、离屏意图和非通知辨识度筛选开放候选；详见 [`STAGE_1_ART_DIRECTION.md`](STAGE_1_ART_DIRECTION.md)与[`STAGE_1_ASSET_CANDIDATES.md`](STAGE_1_ASSET_CANDIDATES.md)。布局和字号将在候选进入真实桌面合成后重新评估。

## 验证命令

```sh
./scripts/run-stage1-visual-tests.sh
```

该脚本运行单元测试、生成视觉矩阵，并分别显示一次 13 pt 与 14 pt 浮层以验证焦点和输入行为。视觉矩阵是可重复的软件场景，不冒充真实 13/14/16 英寸硬件或外接显示器实测。

通知共存矩阵确认按当前布局，顶部通知参考区域与提醒浮层之间保留明显垂直间隔；它只验证空间设计，不冒充真实 Notification Center 并发实测。
